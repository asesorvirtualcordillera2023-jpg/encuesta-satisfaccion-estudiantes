Usuarios, roles y permisos por módulo

Como SUPERADMIN puedes habilitar o retirar módulos individualmente a cada usuario. El rol funciona como plantilla inicial; los permisos personalizados mandan sobre esa plantilla.

Regla de seguridad: los usuarios SUPERADMIN conservan todos los módulos. Para ADMIN_ACADEMICO, ANALISTA y CONSULTA puedes activar o desactivar cada módulo independientemente.

Política de seguridad y privacidad

Diseño aplicado: encuesta anónima, sin datos identificativos del estudiante, RLS, Supabase Auth para administración, auditoría y privilegios mínimos.

Proyecto Supabase configurado. La aplicación ya contiene la URL y la clave pública publishable para el frontend. Nunca uses service_role en este archivo.

const CONFIG = {\n supabaseUrl: 'https://pyvudqszqjpbhessgjzz.supabase.co',\n supabaseAnonKey: 'sb_publishable_eHhXCKgoyB_Swjxix2jCpA_WDU18aQn'\n};
